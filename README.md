# Gallery Heist: The Brushstroke Burglar

A cozy art-forgery caper. Mix paints like real pigment, copy the masterpiece on your easel, and swap it before Bernard the night guard turns around.

**Play:** https://jbarrineau.github.io/gallery-heist/

- 10 original "masterpieces" to forge, from grumpy squares to a portrait of Bernard himself
- Real-feeling paint mixing: red + yellow = orange, white lightens, black darkens
- Paint with brushes or the paint bucket, ask for a recipe when stuck
- Relaxed mode: no clock and no peeking guard

Made for desktop browsers. Everything lives in a single `index.html` (three.js loads from a CDN; all sound is generated in the browser).
